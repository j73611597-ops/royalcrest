# RoyalCrest — PDF 批量签名工具

一款轻量的 Windows 桌面工具，给 PDF 文件批量添加数字签名，不改版面、不破坏原排版。

> 当前版本：**v0.9.0-alpha（内测版）**

## 功能
- 批量给多个 PDF 添加数字签名
- 数字签名嵌在文件里，原版面不改动
- 菜单「帮助 → 检查更新」一键检查最新版本

## 下载
前往 [Releases](https://github.com/j73611597-ops/royalcrest/releases) 下载 `RoyalCrest-Setup.exe`，双击安装即可。

默认安装在用户目录（`%LOCALAPPDATA%\Programs\RoyalCrest`），不需要管理员权限，卸载也干净。

## 使用
1. 运行 RoyalCrest
2. 导入需要签名的 PDF
3. 配置签名（证书 / 签名位置）
4. 开始签名

## 检查更新
菜单「帮助 → 检查更新」，会自动读取最新版本信息。当前为内测版，将来升级到 1.0 时会自动保留全功能授权。

## 说明
- 数字签名证书需自行准备（`.pfx`）。
- 本软件当前为内测阶段，功能已开放，欢迎反馈问题。
